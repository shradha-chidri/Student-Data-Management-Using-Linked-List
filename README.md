# Student Data Management Using Linked List

## Project Description
This project is a Student Data Management System developed using the C programming language and a linked list data structure.

## Features
- Add student records
- Delete student records
- Display student records
- Modify student records
- Save student records to a file
- Sort student records
- Delete all student records
- Reverse the linked list

## Technologies Used
- C Programming Language
- Singly Linked List
- File Handling
- GCC Compiler
- Ubuntu Linux

## How to Compile
gcc -Wall -Wextra -o student stud_main.c stud_add.c stud_del.c stud_mod.c stud_save.c stud_show.c

## How to Run
./student
